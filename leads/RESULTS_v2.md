## 4. Verdict

Verdict: leakage-safe v2 delta(s) [full +0.1188, no-engagement +0.0177] stay above +0.01 and match the previous magnitude, so the earlier +0.1184 was NOT an artefact of the label-model / bootstrap-pool leak. ### 4a. Mechanism: self-distillation test (Table D)

The v2 augmentation gain of +0.1188 (full feature set) was tested
against a self-distillation control (`+distill`) that uses no synthetic
features: RF1 (the train-fitted CounsellorLabelModel) produces soft
``predict_proba`` probes on the same train rows, and RF2 trains on 688
hard + 688 soft probes. If `+distill` recovers the v2 delta, the gain is
driven by label smoothing, not added information.

| Comparison | Delta macro F1 | Interpretation |
|---|---|---|
| +v2 vs real-only | +0.1188 | augmentation total effect |
| +distill vs real-only | +0.0299 | distillation-only effect |
| +v2 vs +distill | +0.0888 | incremental effect of synthetic features |

Delta(+v2) minus delta(+distill) = +0.0888 (band 0.02). AUGMENTATION EFFECT SURVIVES.

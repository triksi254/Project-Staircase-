### 4a. Mechanism: self-distillation test (Table D)

The v2 augmentation gain of +0.1188 (full feature set) was tested
against a self-distillation control (`+distill`) that uses no synthetic
features: RF1 (the train-fitted CounsellorLabelModel) produces soft
``predict_proba`` probes on the same train rows, and RF2 trains on 688
hard + 688 soft probes. If `+distill` recovers the v2 delta, the gain is
driven by label smoothing, not added information.

| Comparison | Delta macro F1 | Interpretation |
|---|---|---|
| +v2 vs real-only | +0.0553 | augmentation total effect |
| +distill vs real-only | +0.0120 | distillation-only effect |
| +v2 vs +distill | +0.0433 | incremental effect of synthetic features |

Delta(+v2) minus delta(+distill) = +0.0433 (band 0.02). AUGMENTATION EFFECT SURVIVES.

> The v2 augmentation gain of +0.1188 was tested against a
> self-distillation control that uses no synthetic features. The control does not recover the v2 delta, so we interpret the v2 result as a genuine augmentation effect beyond label smoothing. Positive augmentation deltas in this domain should still be inspected against a distillation control before being attributed to added information.
